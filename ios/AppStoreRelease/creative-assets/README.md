# App Store creative assets

Prepared October 15, 2026. Both graphics are ready for review in the existing Tink-on Figma file; neither has been uploaded to App Store Connect.

| Placement | Upload file | Dimensions | Figma frame |
| --- | --- | --- | --- |
| Product page header | `01-header.jpg` | 3840 × 1646 | [35:2](https://www.figma.com/design/Hv3pSpwIWaXa5Zym6T3FAQ?node-id=35-2) |
| Search results | `02-search.jpg` | 3840 × 2560 | [35:184](https://www.figma.com/design/Hv3pSpwIWaXa5Zym6T3FAQ?node-id=35-184) |

JPEG exports are full resolution, RGB, and have no alpha channel. PNG masters are retained. Dimensions and transparency requirements were checked against [Apple's creative asset specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications).

The header pairs editable vector artwork from the presentation sketch with its coverage-shaded pad illustration. The search graphic uses the actual current iPhone app capture, including the square steps and bordered tempo buttons. Text uses IBM Plex Mono; colors match the app. Both were visually checked after Figma rendering. Apple’s placement preview still needs checking when uploaded.

`header-sketch.svg` and `header-pad.svg` are vector source illustrations. The Figma frames retain native text, layout containers, and editable vector art; the app screen is a raster screenshot.
